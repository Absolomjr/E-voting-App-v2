# Sacco App

Group SACCO mobile web platform — savings tracking, treasurer verification, member & staff management.

Built alongside **E-voting-App-v2** with the same institutional design system (black / gold / cream).

| Package | Stack |
|---------|--------|
| `sacco-app-frontend` | Next.js 14, React, `src/styles/globals.css` |
| `sacco-app-backend` | Django REST, JWT, Supabase-ready Postgres |

See [`sacco-app-backend/README.md`](./sacco-app-backend/README.md) for architecture, schema, API, and setup.
